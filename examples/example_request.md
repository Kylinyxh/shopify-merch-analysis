# Example Request

Use the `shopify-merchandise-analysis-skill`.

Analyze the attached Shopify files and produce:
1. Full Excel workbook
2. Executive PPT
3. Category advantage analysis
4. Price-band analysis
5. Lifecycle analysis
6. Seasonal adjustment for seasonal products
7. SKU four-quadrant analysis
8. Inventory-risk and forward-coverage analysis
9. SKU decisions: clearance, bundle, price increase, reduce discount, restock, exposure, stop restock

Important:
- Classify products by actual product identity; do not merge unrelated products for convenience.
- Do not use Compare-at Price alone as proof of real discounting.
- Show the measurement period on every table and analytical slide.
- Every chart must have labels and a written conclusion.
