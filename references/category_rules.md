# Category Rules

## Principle

Classify by actual product identity. Do not merge unrelated items for convenience.

Priority:
1. Title / actual identity
2. Shopify Product Category
3. Product Type
4. Website taxonomy
5. Image validation

## Bikes

Bikes contains complete bicycles only.

Explicitly exclude:
- Bike Lights
- Inner Tubes
- Bike Trainers
- Cycling Masks
- Bicycle Saddles
- Handlebar Tape
- Bike Wheels / Wheelsets
- Tools / Tool Accessories
- Pedals
- Pumps
- Bags
- Locks
- Mirrors
- Racks
- Tires
