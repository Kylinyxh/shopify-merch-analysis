# Shopify SKU Decision Tool — Stateless Skill

这是一个**完全无历史数据**的商品经营决策 Skill。

## 每次使用都必须重新上传

1. 产品文件
2. 销量文件
3. 库存文件
4. 利润 / 成本文件

然后说：

**按照本次数据重新生成决策工具**

Skill 会从本次文件重新计算并生成：

- HTML SKU 决策查询工具
- Excel 完整商品经营分析
- PPT 管理层汇报

## Skill 内不会保存

- 任何真实 SKU
- 产品标题
- 产品清单
- 销量
- 库存
- 利润率
- 成本
- 品类映射
- 季节指数
- 价格带
- 仓库名称
- 品牌名称
- 之前生成的分析结果

## 四个月季节判断

每次自动根据当前日期判断：

**当前月 + 未来3个月**

每个月显示：
- 标准化季节指数
- 淡季 / 偏淡 / 平季 / 偏旺 / 旺季

## 推荐销量历史

最好每次上传 18–24 个月以上的月度销量历史。

这样可以更可靠地重新计算：
- 季节指数
- 同比
- 近期趋势
- 生命周期趋势
- 品类价格带结构

## 输出逻辑

HTML 用于单 SKU 查询。

Excel 用于完整计算、明细和审计。

PPT 用于品类结论和管理层汇报。

## 一句话使用方式

> 上传本次产品 + 销量 + 库存 + 利润/成本文件，然后说“按照本次数据重新生成决策工具”。
